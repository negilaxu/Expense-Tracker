# Expense Tracker

A simple browser-based monthly expense tracker built with HTML, CSS, and JavaScript.

## Features

- Select a month and year
- Add expenses by category
- Track:
  - Housing
  - Food
  - Bills
  - Transportation
  - Miscellaneous
- View expenses in a chart
- Save expense data in browser local storage
- Prevent expense categories from going below zero
- Responsive layout for mobile screens

## How to Run

1. Clone or download this project.
2. Open `index.html` in a web browser.
3. Select a month, year, category, and amount.
4. Click **Add Expense**.

No build tools or installation are required.

## Technologies

- HTML5
- CSS3
- JavaScript
- Chart.js
- Browser Local Storage

## Note

Chart.js is loaded from the jsDelivr CDN, so an internet connection may be required for the chart to display.
